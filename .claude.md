# LaboRemoto - Contexto del Proyecto

## 📋 Descripción General

**LaboRemoto** es una plataforma educativa de laboratorio remoto que permite a estudiantes acceder y controlar equipos de laboratorio (Raspberry Pi, Arduino, etc.) desde cualquier lugar. 

- **Frontend:** React + TypeScript (Vite)
- **Backend:** Rust + Tauri v2
- **Integraciones:** Claude AI, Moodle LMS, SSH/SFTP, GPIO, Arduino, VNC, WebRTC
- **Ubicación:** `Cliente-Rust/`

---

## 🎯 Objetivo Actual: Refactorización de Arquitectura

Estamos implementando 5 refactores prioritarios identificados en la revisión arquitectónica:

### **REFACTOR #1 (PRIORITARIO):** Versionar Comandos Tauri
- **Problema:** 80+ comandos sin versioning; cambios silenciosos rompen frontend
- **Solución:** Envolver comandos en schema versionado
- **Archivos:** `backend/src/cmd/protocol.rs`, `backend/src/lib.rs`, `frontend/src/services/*`

### **REFACTOR #2 (PRIORITARIO):** Consolidar Session Management
- **Problema:** Dos session stores (Tauri + REST); sin distributed sessions
- **Solución:** SessionManager trait con in-memory + Redis backends
- **Archivos:** `backend/src/session_manager/`, `backend/src/lib.rs`

### **REFACTOR #3 (MEDIANO):** Error Handling Estructurado
- **Problema:** Errores opacos; frontend no sabe si reintentar
- **Solución:** CommandError enum con categorización (transient, permanent, etc)
- **Archivos:** `backend/src/cmd/error.rs`, todos los handlers

### **REFACTOR #4 (MEDIANO):** Refactor Frontend State
- **Problema:** 20+ refs en terminal; Context API incompleto
- **Solución:** Zustand + extract useTerminalSession hook
- **Archivos:** `frontend/src/store/`, `frontend/src/hooks/`

### **REFACTOR #5 (MEDIANO):** Real-time Sync Contract
- **Problema:** Eventos fire-and-forget se pierden
- **Solución:** mpsc channels + ACK + backpressure
- **Archivos:** `backend/src/ipc/`, todos los handlers

## 🔐 Convenciones & Reglas

### **Backend (Rust)**
- Errores: Use `Result<T, CommandError>` (nuevo enum)
- Sessions: Inyectar `Arc<SessionManager>` en Tauri state
- Commands: Wrappear en `CommandRequest<T>` / `CommandResponse<T>`
- Logging: Usar `tracing::` crate para structured logging

### **Frontend (TypeScript)**
- State: Zustand stores en `src/store/`
- Hooks: Lifecycle logic en `src/hooks/`, ej: `useTerminalSession`
- Services: Tauri wrappers en `src/services/`, ej: `sshService.ts`
- Types: Sincronizar con backend (usar `ts-rs` si es posible)

### **Testing**
- Unit: `backend/tests/` (auth, state_core)
- Integration: `backend/tests/integration/` (SSH+SFTP flow)
- E2E: `frontend/tests/e2e/` (Playwright)
